# Kiki eSIM native iPhone screen library

- App build: 1.0.24 (27)
- Device: iPhone 17 Pro simulator
- iOS: 26.5
- Native screenshot size: 1206 × 2622 pixels
- Screen and state captures: 78

Open `gallery.html` to browse every capture. `manifest.json` lists the exact dimensions and path of every screen. `00-contact-sheets` contains compact category overviews.

The library includes route screens plus important interactive states: all four Home heroes, scrolled Home sections, search/filter/no-result Plans states, all three My eSIM tiers, crew-verification sheet and completed email field, roster date-entry sheet, payment-method choices, reward-card expansion, flight journey animation states, greeting language sheet, location permission, and the first safe account-deletion confirmation.

Safety boundary: no account was deleted, no purchase was submitted, and no real OTP email was sent. The crew-verification sequence therefore stops at the filled email state.
